**Период практики:** 01.05.2026 – 15.05.2026

## 2026-05-15

### Добавлено (Added)

- **Модуль управления моделями ИИ:** Разработан интерфейс для импорта пользовательских моделей (.pt, .h5).
- **Интеграция SQLite:** Реализована база данных для хранения метаданных моделей (точность, дата загрузки, описание) и сохранения состояния "Активной модели".
- **Динамическое переключение моделей:** Реализован механизм ValueNotifier для мгновенного обновления UI (Sidebar) при активации новой модели.
- **Backend API (FastAPI):** Разработан эндпоинт `/api/analyze`, поддерживающий динамическую загрузку весов ИИ на лету на основе параметров запроса.
- **Автоматизация файловой системы:** Добавлена логика автоматического копирования импортированных файлов в директорию `assets/models/` проекта.

### Изменено (Changed)

- **Архитектура базы данных:** Обновлен класс `DatabaseHelper`, добавлена миграция для таблицы `modelos`.
- **Локализация (i18n):** Добавлены новые строки перевода для всех элементов управления моделями на испанском и английском языках.
- **Интерфейс анализа:** Обновлен `UploadPanel` для отправки названия выбранной модели в сторону Python-бэкенда.

### Исправлено (Fixed)

- **Git TLS Error:** Устранена проблема подключения к удаленному репозиторию GitHub через настройку `http.sslBackend schannel`.
- **Управление состоянием:** Исправлены ошибки рендеринга при обновлении списка моделей из базы данных.
